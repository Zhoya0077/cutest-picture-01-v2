# Strawberry-Hat Kitten in a Basket

A tiny fluffy white kitten with huge sparkling blue eyes peers out from a basket of ripe strawberries, wearing a hand-knitted strawberry hat. Its small paws rest on the basket's edge, and soft pink bokeh light glows behind it.

The picture is built from soft round shapes: a plump fluffy face, enormous starry eyes, and a cozy knitted hat with green leafy sprouts. The deep red strawberries against the kitten's white fur give the whole scene a warm, sweet contrast, and the big-eyed face still reads clearly when viewed small.

## Running the entry

Run the program from the repository root with python3 main.py.

The program copies entry.png into the output directory given by MAKEFUN_OUTPUT_DIR, or /output by default. It uses only the Python standard library and needs no network access.
